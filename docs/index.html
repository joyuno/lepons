Lepons

여러 PC의 Claude Code와 Codex를 한 화면에서 부리고, PC끼리 코드베이스를 실시간으로 나눠 읽게 하는 데스크톱 앱입니다.

무료로 받기 Windows 10/11 · macOS (Apple Silicon) · MIT 라이선스

이런 분께 맞습니다

  • 서버, 워크스테이션, 맥북마다 터미널을 따로 띄워 Claude Code나 Codex를 돌리고 있는 분
  • 한 PC의 에이전트가 다른 PC의 코드를 봐야 해서 git push·pull이나 파일 복사를 반복하는 분
  • 여러 에이전트가 지금 무엇을 하는지, 요금제 사용량이 얼마나 남았는지 한눈에 보고 싶은 분

주요 기능

  • PC 간 코드베이스 공유 — 공유 맵에서 폴더를 다른 PC 위로 끌어다 놓으면, 그 PC의 Claude Code·Codex가 MCP로 이 폴더를 읽고 검색합니다. 필요한 파일만 그때그때 읽어 토큰을 아낍니다.
  • 패널 분할 — 최대 네 개 패널에 서로 다른 PC의 세션과 파일을 나란히 둡니다.
  • 원격에 설치할 것 없음 — SSH만 되면 됩니다. 처음 한 번 비밀번호를 넣으면 SSH 키를 대신 등록합니다.
  • 끊겨도 계속되는 작업 — 원격 세션은 tmux에서 돌아, 노트북을 덮어도 에이전트는 일을 계속합니다.
  • 워크플로우 보드 — 세션과 서브에이전트, PC 사이의 위임을 한 보드로 봅니다.
  • 사용량 배터리 — Claude·Codex 요금제의 5시간·7일 한도 남은 양을 배터리로 보여 줍니다.

다른 도구와 비교

도구하는 일Lepons와 다른 점
VS Code + Remote-SSH원격에 VS Code Server를 설치해 원격 개발Lepons는 원격에 아무것도 설치하지 않고, 여러 PC의 에이전트 세션을 한 창에 둡니다
cmuxmacOS 전용 터미널로 여러 에이전트 관찰Lepons는 Windows·macOS 모두, PC끼리 코드 공유까지 합니다
일반 SSH 클라이언트연결까지만Lepons는 에이전트 선택·업데이트·상태 표시까지 합니다

시작하기

  1. 최신 버전을 받아 설치합니다.
  2. ＋ PC 추가 → 원격 PC에 사용자@IP주소를 넣습니다.
  3. 폴더를 누르고 Claude Code 또는 Codex를 고릅니다.

자세한 사용법은 GitHub README에 있습니다.
