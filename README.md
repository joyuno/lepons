<h1 align="center">Lepons</h1>

<p align="center">여러 머신(Local, VM)에서 돌아가는 Claude Code와 Codex를 한 화면에서 여러개로 분할하여 볼 수 있고, 탐색기 기능을 제공하며, 머신(VM)끼리 실시간으로 코드베이스를 공유하여 개발할 수 있는 데스크톱 앱입니다.</p>

서버, 워크스테이션, 맥북처럼 흩어진 머신마다 터미널을 따로 띄우고 코드나 파일을 복사해 옮기던 일을 한곳으로 모읍니다. 원격 머신에는 아무것도 설치하지 않습니다. SSH 접속만 되면 됩니다.

## 다운로드

**[최신 버전 받기](https://github.com/joyuno/lepons/releases/latest)**

| 운영체제 | 파일 |
|---|---|
| Windows 10/11 | `.exe` 설치 파일 |
| macOS (Apple Silicon, M1 이상) | `.dmg` |

### 설치

- **Windows**: 받은 `.exe`를 실행합니다. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. 코드 서명 인증서가 없는 앱이라 뜨는 경고입니다. 브라우저가 다운로드를 막으면 **유지**를 고릅니다.
- **macOS**: `.dmg`를 열고 Lepons Cockpit을 응용 프로그램 폴더로 끌어다 놓습니다. Apple 공증을 받지 않은 앱이라, 처음 열 때 "손상되었기 때문에 열 수 없습니다"나 "확인되지 않은 개발자" 경고가 뜰 수 있습니다. 그러면 터미널에서 아래 명령을 한 번 실행한 뒤 다시 엽니다.

  ```sh
  xattr -dr com.apple.quarantine "/Applications/Lepons Cockpit.app"
  ```

## 장점

1. **원격 머신 간 코드베이스 공유**: 공유 맵에서 폴더를 다른 머신 위로 끌어다 놓으면, 그 머신의 에이전트가 이 폴더를 읽고 검색할 수 있습니다. git push·pull도, 파일 복사도 필요 없습니다. 상대는 읽기만 할 수 있고, 키·토큰처럼 보이는 값은 가려서 보냅니다. 다른 머신의 에이전트에게 일을 맡기고 진행 상황을 확인할 수도 있습니다.
2. **자유로운 패널 분할**: 오른쪽이나 아래로 나눠 최대 네 개의 패널을 띄웁니다. 패널마다 다른 머신의 세션이나 파일을 놓고 나란히 봅니다.
3. **Claude Code·Codex 자동 업데이트와 실행**: 폴더를 누르고 Claude Code, Codex, 터미널 중 하나를 고르면 그 폴더에서 바로 열립니다. Lepons를 켠 뒤 머신마다 첫 실행 때 CLI를 최신 버전으로 올리고 시작합니다. 모델은 CLI의 최신 기본 모델을 따르고, 지난 대화를 이어서 시작할 수도 있습니다.
4. **끊겨도 계속되는 작업**: 원격 세션은 tmux 위에서 돌아갑니다. 노트북을 덮거나 네트워크가 끊겨도 에이전트는 하던 일을 계속하고, 다시 열면 그 화면에 그대로 붙습니다.
5. **원격 머신에 설치할 것 없음**: 데몬도, 서버 프로그램도 없습니다. 세션도, 코드 공유도 SSH로만 오갑니다. (단, Lepons MCP 설치 시 코드베이스 공유 가능)
6. **패널 안에서 파일 보기·편집**: 마크다운(옵시디언 문법 포함), 코드, 이미지, PDF, HTML을 패널 안에서 보고, 이 PC와 원격 머신의 파일을 그 자리에서 고칩니다. 파일 트리는 VS Code처럼 우클릭으로 복사·붙여넣기·이름 바꾸기·삭제·경로 복사를 합니다.
7. **한눈에 보는 워크플로우**: 세션마다 Claude Code·Codex가 지금 무엇을 하는지, 머신 사이에 어떤 일이 오갔는지를 보드 하나로 봅니다.
8. **이미 쓰던 곳에서 불러오기**: VS Code·Cursor가 기억하는 원격 폴더와 Claude Code·Codex의 세션 기록에서 머신과 폴더를 한 번에 가져옵니다.

## 다른 도구와 다른 점

- **cmux**는 Ghostty 기반의 macOS 전용 네이티브 터미널로, 세로 탭과 알림으로 여러 에이전트를 지켜보게 해 줍니다. Lepons는 Windows와 macOS에서 돌고, 터미널을 넘어 머신끼리 코드를 나눠 읽게 하는 데까지 갑니다.
- **VS Code + Remote-SSH**는 원격 머신에 VS Code Server를 설치해 원격 개발 환경을 만듭니다. Lepons는 원격에 아무것도 설치하지 않고, 여러 머신의 에이전트 세션을 한 창에 나란히 둡니다.
- **일반 터미널·SSH 클라이언트**는 연결까지만 해 줍니다. Lepons는 세션마다 에이전트를 고르고, 최신으로 유지하고, 무엇을 하는지 보여 줍니다.

## 시작하기

### 원격 머신 준비

- SSH 키로 접속할 수 있을 것
- tmux (권장. 없으면 연결이 끊길 때 그 세션의 작업도 끝납니다)
- Claude Code 또는 Codex 설치와 로그인

### 첫 연결

처음 실행하면 화면을 따라가며 주요 버튼을 짚어 주는 안내가 나옵니다. 다시 보려면 왼쪽 위 전원 버튼 → **이용 가이드**를 누릅니다.

1. 왼쪽 아래 **＋ 머신 추가 → 원격 머신**에서 `<VM 사용자 이름>@<연결할 VM IP주소 또는 호스트명>`을 입력합니다. 예: `ubuntu@10.0.0.5`
2. 그 머신에 Lepons 키가 아직 없으면 비밀번호 칸이 나옵니다. 한 번 입력하면 Lepons가 키를 `~/.ssh/authorized_keys`에 대신 넣고, 그 뒤로는 키로 연결합니다. 비밀번호는 저장하지 않습니다.
   - 서버가 비밀번호 로그인을 막아 두었다면 **＋ 머신 추가 → 연결 가이드**에서 이 PC의 Lepons 공개키를 복사해 원격 머신의 `~/.ssh/authorized_keys`에 붙여 넣습니다.
3. 머신에 폴더를 추가하고, 왼쪽 목록에서 폴더를 누릅니다. Claude Code, Codex, 터미널 중 하나를 고르면 그 폴더에서 시작합니다.
4. 머신끼리 프로젝트 데이터를 공유하려면 **공유 맵**에서 폴더를 다른 머신 위로 끌어다 놓습니다.

VS Code나 Claude Code, Codex로 이미 작업하던 곳이 있다면 **＋ 머신 추가 → 불러오기**로 머신과 폴더를 한 번에 가져올 수 있습니다.

### 코드 공유 방식

- 공유 맵에서 연결하면 Lepons가 SSH 연결 위에 역방향 터널을 열고, 그 머신의 Claude Code·Codex에 Lepons MCP를 등록합니다. 이미 열려 있던 세션에는 **lepons 적용** 버튼이 떠서, 누르면 대화를 이어 가며 다시 엽니다.
- 공유받은 쪽 에이전트는 `search_repo`로 검색하고 `read_file`로 필요한 파일만 엽니다. Lepons는 요청이 올 때마다 원래 머신에서 그 파일이나 검색에 걸린 줄만 읽어 전달합니다.
- 저장소를 통째로 복사하거나 미리 보내지 않습니다. 에이전트가 실제로 읽은 부분만 컨텍스트에 들어가므로 그만큼만 토큰을 씁니다.

### 업데이트

Lepons를 켤 때와 왼쪽 위 전원 버튼의 **업데이트 확인**을 누를 때 지금 버전을 GitHub의 최신 릴리스와 비교합니다. 새 버전이 있으면 알림이 뜨고, **지금 업데이트**를 눌러 앱 안에서 받습니다. 받은 파일이 GitHub에 올린 것과 같은지 확인한 뒤 설치하고, Lepons는 잠깐 닫혔다가 새 버전으로 다시 열립니다. Electron이 그대로인 릴리스는 바뀐 앱 부분(약 13MB)만 받습니다. macOS는 이 작은 업데이트만 앱 안에서 하고, 그 밖의 릴리스는 다운로드 페이지를 엽니다. 등록한 머신과 설정은 업데이트해도 그대로 남습니다.

## Lepons가 연결하는 곳

- 사용자가 추가한 머신: SSH로만 접속합니다.
- GitHub: Lepons를 켤 때와 **업데이트 확인**을 누를 때 최신 릴리스를 물어보고, **지금 업데이트**를 누르면 그 릴리스의 파일을 받습니다.
- 그 밖에 Lepons가 직접 보내는 데이터는 없습니다.(즉, 토큰을 최소한으로 사용하며 코드베이스 공유가 가능합니다.) Claude Code와 Codex는 각자의 서비스에 연결하고, 첫 실행 때 각자의 업데이트 명령으로 최신 버전을 받습니다.

화면 언어는 한국어, 영어, 중국어를 지원하며, 전원 버튼 → **언어**에서 바꿉니다. 문제나 제안은 [Issues](https://github.com/joyuno/lepons/issues)에 남겨 주세요.
